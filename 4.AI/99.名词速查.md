# 名词速查

该文档包含多个名词的中英文对应及简要的解释说明，方便快速查阅。

| 英文                                             | 中文             | 说明                                                          |
| ------------------------------------------------ | ---------------- | ------------------------------------------------------------- |
| FNN<br>_Feedforward Neural Network_              | 前馈神经网络     | 一种最基本的神经网络结构，信息单向流动。其中包含了CNN和FCNN等 |
| FCNN<br>_Fully Connected Neural Network_         | 全连接神经网络   | 线性层和非线性层组合，中间利用多个隐藏层来提高模型表达能力    |
| RNN<br>_Recurrent Neural Network_                | 循环神经网络     | 适用于处理序列数据的深度学习模型                              |
| CNN<br>_Convolutional Neural Network_            | 卷积神经网络     | 通过卷积核提取图像特征的深度学习模型                          |
| PPO<br>_Proximal Policy Optimization_            | 近端策略优化     | 一种强化学习算法，常用于训练智能体进行决策和控制任务          |
| DPO<br>_Direct Preference Optimization_          | 直接偏好优化     | 一种无需奖励模型的强化学习算法，直接从人类反馈中学习偏好      |
| GRPO<br>_Generalized Reward Policy Optimization_ | 广义奖励策略优化 | 一种强化学习算法，旨在优化智能体的奖励策略                    |
