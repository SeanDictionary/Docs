# LLM

LLM (Large Language Model，大型语言模型)是指一种基于深度学习的自然语言处理模型，通常具有数十亿甚至数百亿的参数，能够理解和生成自然语言文本。LLM 的核心技术包括 Transformer 架构、注意力机制以及大规模预训练和微调方法。

现在关于LLM的主要部分有如下几点：

- 数据采集和分词器
  - 数据采集与清洗（预训练语料构建、去重、去毒、质量过滤）
  - **分词器**（BPE / SentencePiece / WordPiece，词表大小选择）
- 模型架构
  - **Transformer**（Encoder / Decoder / Encoder-Decoder）
  - 注意力机制（MHA / GQA / MQA）
  - 位置编码（RoPE / ALiBi / 绝对位置）
  - 归一化（LayerNorm / RMSNorm）、激活函数（SwiGLU / GELU）
  - MoE（混合专家）
- 预训练
  - 训练目标（CLM / MLM）
  - 优化器与调度（AdamW、Cosine LR）
  - 混合精度训练（FP16 / BF16 / FP8）
  - **分布式训练**（数据并行 / 张量并行 / 流水并行 / ZeRO）
  - **Kernel 优化**（FlashAttention、 fused kernel、自定义算子）
  - 稳定性（梯度裁剪、loss spike 处理）
- 后训练
  - SFT（监督微调）
  - RLHF（PPO / 奖励模型）
  - DPO / ORPO（免 RL 对齐方法）
  - 安全对齐、拒答训练
  - Instruction Tuning（指令微调）
- 生成与推理
  - 解码策略（Greedy / Beam / Top-k / Top-p / Temperature）
  - **KV Cache**（Prefix Cache、PagedAttention）
  - **量化**（INT8 / INT4 / GPTQ / AWQ）
  - 推理框架（vLLM / TensorRT-LLM / TGI / Triton / Ollama ...）
  - 投机解码（Speculative Decoding）
- 应用扩展
  - 提示工程（CoT / Few-shot）
  - **RAG**（检索增强生成）
  - **Agent**（工具调用、规划、多轮）
  - 长上下文处理

## 模型参数

对于现在发布的模型，能发现都会带上模型的规模参数，像是 qwen3.5-8B、deepseek-v3-671B 等等

这里指的参数大小是指模型中可训练的参数数量，包括了权重矩阵、偏置向量等。参数数量越多，模型的容量和表达能力通常也越强，但同时也会带来更高的计算和存储成本。

对于有一些模型写作deepseek-v3-w671a37-fp8，表示这个模型权重参数为 671B，每一个输入token在推理时只需要 37B 的激活参数进行运算。同时该模型采用了 FP8 的量化方式进行推理，减少了显存占用和计算量。

## Tokenization

Tokenization 是将文本分解为更小的单元（称为 token）的过程，这些 token 可以是单词、子词或字符。
