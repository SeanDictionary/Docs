# AWD

AWD流程通常分为加固和攻击两个阶段，加固阶段不能发起攻击，攻击阶段中每一轮可以攻击获取flag提交以此获得积分。此外裁判机会定时check靶机状态，若被攻击或服务非正常运行则会扣分

通常主办方会给每个队伍提供一模一样环境的一个或多个靶机用于加固和攻击，线下AWD靶机通过物理交换机连接至同一局域网，可以通过赛方提供的ssh连接靶机进行操作。常用windterm、VSCode进行ssh连接

## 加固阶段

关于靶机，一般AWD靶机会包含web和pwn两个方向，通常只会提供的www-data用户用于ssh，没有超管权限。

#### Apache

配置Apache `.htaccess`

```apache
<Directory "/var/www/html/upload">                              //指定目录后续的指令将应用于该目录
Options -ExecCGI -Indexes                                       //禁用了目录中的 CGI 执行和目录索引（显示目录内容列表）功能。
AllowOverride None                                              //不允许在该目录中使用 .htaccess 文件来覆盖服务器的配置。
RemoveHandler .php .phtml .php3 .pht .php4 .php5 .php7 .shtml
RemoveType .php .phtml .php3 .pht .php4 .php5 .php7 .shtml
//这两个指令移除指定文件扩展名的处理器和类型。
//在这种情况下，这些指令从 Apache 的处理列表中移除了与 PHP 相关的扩展名和服务器端包含（SSI）文件类型。
php_flag engine off                                             //这个指令将 PHP 的引擎标志（engine）设置为关闭状态，从而禁用了在该目录中执行 PHP 脚本的能力。
<FilesMatch ".+\.ph(p[3457]?|t|tml)$">
deny from all
</FilesMatch>                                                   //这三行命令使用正则表达式匹配了以 .php、.phtml、.php3、.pht、.php4、.php5、.php7、.shtml 结尾的文件，并将其访问权限设置为拒绝所有
</Directory>
```

#### Nginx

配置Nginx `/etc/nginx/nginx.conf`

```nginx
worker_processes auto;
events {
    worker_connections 2048;
}

http {

    include       mime.types;
    default_type  application/octet-stream;

    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 30;

    server_tokens off;  # 隐藏版本号
    autoindex off;      # 禁止目录索引

    # =============================
    # 限制连接数（防止简单DoS）
    # =============================
    limit_conn_zone $binary_remote_addr zone=addr:10m;
    limit_req_zone $binary_remote_addr zone=req_limit:10m rate=10r/s;

    server {
        listen 80 default_server;
        server_name _;
        root /var/www/html;
        index index.php index.html;

        # 单IP最大连接数
        limit_conn addr 30;

        # 请求速率限制（不影响正常用户）
        limit_req zone=req_limit burst=20 nodelay;

        # =============================
        # 正常业务入口
        # =============================
        location / {
            try_files $uri $uri/ /index.php?$args;
        }

        # =============================
        # 禁止访问隐藏文件
        # =============================
        location ~ /\.(?!well-known).* {
            deny all;
        }

        # =============================
        # 禁止目录遍历
        # =============================
        location ~ \.\. {
            deny all;
        }

        # =============================
        # 禁止访问备份/源码文件
        # =============================
        location ~* \.(sql|bak|old|log|sh|conf|swp)$ {
            deny all;
        }

        # =============================
        # 上传目录禁止执行PHP（核心防shell）
        # =============================
        location ^~ /upload/ {
            location ~ \.php$ {
                deny all;
            }
        }

        # =============================
        # 只允许 GET/POST
        # =============================
        if ($request_method !~ ^(GET|POST)$ ) {
            return 444;
        }

        # =============================
        # 简单过滤明显恶意参数（低误伤）
        # =============================
        if ($query_string ~* "(benchmark|sleep\(|union.*select|into.*outfile)") {
            return 403;
        }

        # =============================
        # PHP 处理
        # =============================
        location ~ \.php$ {
            include fastcgi_params;
            fastcgi_pass unix:/run/php/php8.1-fpm.sock;
            fastcgi_index index.php;

            fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        }

        # =============================
        # 禁止直接访问配置目录
        # =============================
        location ^~ /config/ {
            deny all;
        }

        # =============================
        # 禁止访问 vendor 可执行脚本（可选）
        # =============================
        location ~* /vendor/.*\.(php)$ {
            deny all;
        }

        # =============================
        # 错误页面
        # =============================
        error_page 403 /403.html;
        error_page 404 /404.html;
    }
}
```

### 应急响应

进程审计，主要可以过滤含有bash或者外连的进程

```bash
netstat
netstat -apt
ps -aux                 #查看所有进程
ps -ef --forest         #显示进程树，查看父子关系
ps -aux | grep "www-data|apache|nginx|php|java"   #过滤web相关进程


kill -9 pid             #Linux上
taskkill /f /pid pid    #Windows上

kill ps -aux | grep www-data | grep apache2 | awk '{print $2}'  #查找www-data用户的apache2进程并杀死
```

查找 `webshell` 文件

```bash
find /var/www/html -name *.php -mmin -5                                 //查看最近5分钟修改文件
find ./ -name '*.php' | xargs wc -l | sort -u                           //寻找行数最短文件，一般有可能是一句话木马
grep -r --include=*.php  '[^a-z]eval($_POST'  /var/www/html             //查包含关键字的php文件
find /var/www/html -type f -name "*.php" | xargs grep "eval(" | more    //在Linux系统中使用find、grep和xargs命令的组合，用于在指定目录（/var/www/html）下查找所有以.php为扩展名的文件，并搜索这些文件中包含字符串"eval("的行，并使用more命令来分页显示结果以便在输出较长时进行逐页查看
```
