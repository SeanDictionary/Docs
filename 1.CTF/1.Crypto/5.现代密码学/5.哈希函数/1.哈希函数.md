# 哈希函数

哈希函数又称为散列函数，是一种将任意大小的数据映射到固定大小的输出的函数。哈希函数广泛应用于数据结构、密码学和信息安全等领域。

哈希函数同样又称消息摘要函数，这表示哈希函数对于不同的输入是具有唯一性的输出的。也就是说抗碰撞性。但又鉴于哈希函数的输入长度不定，输出长度固定，也就导致了碰撞一定是存在的。

常见的哈希函数有：MD5、SHA-1、SHA-256 等等。

在 Python 标准库`hashlib`中封装了常见的哈希函数，可以直接使用。

目前，MD5、SHA-1 已经认定为不安全的哈希函数，在实际使用中不推荐使用这些算法作为消息摘要函数。

虽然上面两个哈希函数已经说明是不安全的了，但是并不意味着就能对任何一个哈希值进行逆向或者碰撞。而且实际上使用也不太用过于担心其安全性。除非出题人魔改过算法，不然这类哈希算法没有什么可玩性。

下面讲一种有点意思但不常见的哈希函数 FNV

## FNV

FNV 算法分为好几个版本，有 FNV-1、FNV-1a、FNV-0、FNV-0a 等。

FNV-1 和 FNV-1a 是最常用的版本，FNV-1a 是 FNV-1 的变种。

FNV-1 的 python 实现如下：

```python
def fnv_1(data: bytes, base: int = 0x811C9DC5) -> int:
    """FNV-1哈希函数"""
    for byte in data:
        base *= 0x01000193  # 乘以FNV质数
        base &= 0xFFFFFFFF  # 保持32位
        base ^= byte  # 异或操作
    return base
```

FNV-1a 的 python 实现如下：

```python
def fnv_1a(data: bytes, base: int = 0x811C9DC5) -> int:
    """FNV-1a哈希函数"""
    for byte in data:
        base ^= byte  # 异或操作
        base *= 0x01000193  # 乘以FNV质数
        base &= 0xFFFFFFFF  # 保持32位
    return base
```

依据 FNV-1 的定义，可以得到这样的推导式子

$$
h_1=xh_0+b_1\ mod\ M
$$

$$
h_{i+1}=xh_i+b_{i+1}\ mod\ M
$$

$$
h_n=x^nh_0+x^{n-1}b_0+x^{n-2}b_1+\dots +xb_{n-1}+b_n\ mod\ M
$$

然后就能构造出这样的格

$$
(b_n,b_{n-1},\dots,b_1,1,k)
\begin{pmatrix}
1& & & & &x^0\\
 &1& & & &x^1\\
 & &\ddots& & &\vdots\\
 & & &1& &x^{n-1}\\
 & & & &1&x^nh_0-C\\
 & & & & &M\\
\end{pmatrix}=
(b_n,b_{n-1},\dots,b_1,1,0)
$$

检查一下 *Hermit* 定理，然后用$k$配平即可

这样的计算出来的字符串对于较小长度的字符串来说可以完全恢复，对于较长的字符串，就只能得到哈希值相同的字符串
