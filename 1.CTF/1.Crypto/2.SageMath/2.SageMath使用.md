# SageMath 使用

可以把 SageMath 理解为一个集成了大量数学库的 Python 环境，例如 NumPy、SciPy、SymPy 等。使用方法和 Python 类似。

这里只讲解一些和 Python 不同的特殊部分

**Integer**：SageMath 中的整数类型默认是 `Integer`，而不是 Python 中的 `int`。因此 python 中常用的对 `int`类型的方法在 SageMath 中使用会报错，需要用 `int()`来转换类型，例如 `int(12345).bit_length()`、`long_to_bytes(int(12345))`。默认整数类型带有一些实用方法，例如 `Integer(12345).factor()`来分解质因数，`Integer(12345).is_prime()`来判断是否为素数，`Integer(12345).nth_root()`来求整数在当前环上的 n 次根。

**基本的环、域**：SageMath 中有很多内置的环和域，例如 `GF(p)`表示有限域，`Zmod(n)`表示整数模 n 的环，`ZZ`表示整数环，`QQ`表示有理数域，`RR`表示实数域，`CC`表示复数域，`PolynomialRing`表示多项式环等等。

**多项式**：SageMath 中的多项式是一个类，可以使用 `PolynomialRing`来创建多项式环，例如 `R.<x> = PolynomialRing(GF(31))`表示有限域上的多项式环 `R`，含有一个变量 `x`。用 `f = x^2 + 2*x + 3`来表示该环上的多项式。用 `f.roots()`来求多项式的根，`f.factor()`来分解多项式，`f.derivative()`来求导等等。

**矩阵**：SageMath 中的矩阵是一个类，可以使用 `Matrix`来创建矩阵，例如 `M = Matrix(GF(31), 2, 2, [1, 2, 3, 4])`表示一个$2\times2$的在$GF_{37}$上的矩阵。用 `M.eigenvalues()`来求特征值，`M.eigenvectors()`来求特征向量，`M.charpoly()`来求特征多项式等等，`M.jordan_form()`来求 Jordan 标准型等等。此外还有 `zero_matrix`、`identity_matrix`、`diagonal_matrix`、`block_matrix`等函数来创建零矩阵、单位矩阵、对角矩阵和块矩阵。

**中国剩余定理 CRT**：SageMath 中有内置的实现 CRT 的函数，可以直接使用 `crt()`来求解同余方程组，例如 `crt([m_1,m_2],[p_1,p_2])`表示求解同余方程组

$$
\left\{\begin{matrix}
x\equiv m_1\ mod\ p_1 \\
x\equiv m_2\ mod\ p_2
\end{matrix}\right.
$$

**pow**：SageMath 中的 `pow(a,b,n)`函数经过重载，返回值默认处在$Zmod(n)$环上，后续参与的计算也会在该环上进行。
