# 汇编

## 寄存器

寄存器是CPU内部的高速存储单元，用于存储数据和指令。不同的寄存器有不同的用途和功能。在x86-64架构中，常用的寄存器包括：

- `rax`：累加器寄存器，常用于存储函数的返回值。
- `rbx`：基址寄存器，常用于存储数据的基址。
- `rcx`：计数寄存器，常用于存储循环计数器。
- `rdi`：目的索引寄存器，常用于存储函数的第一个参数。
- `rdx`：数据寄存器，常用于存储函数的第二个参数。
- `rsi`：源索引寄存器，常用于存储函数的第三个参数。
- `rsp`：栈指针寄存器，指向当前栈顶的位置。
- `rbp`：基指针寄存器，指向存储当前函数的栈帧基址。
- `rip`：指令指针寄存器，指向当前正在执行的指令地址。

## 栈

栈是一个后进先出（LIFO）的数据结构，用于存储函数调用的相关信息，如返回地址、参数和局部变量。栈在程序执行过程中动态分配和释放内存。并且在x86架构中，栈通常向下增长，即从高地址向低地址扩展。例如

```
高地址 （栈底）
│   old data
├──────────────
│  函数参数
├──────────────
│  返回地址
├──────────────
│  保存的 rbp
├──────────────
│  局部变量
│  char buf[64]
↓
低地址 （栈顶）
```

### 栈指针

栈指针（Stack Pointer，SP）是一个寄存器，用于指向当前栈顶的位置。在x86-64架构中，栈指针寄存器是 `rsp`。当函数被调用时，返回地址被压入栈中，并且 `rsp` 会自动调整以指向新的栈顶位置。当函数执行完毕后，返回地址被弹出栈中，并且 `rsp` 会恢复到之前的位置。

### 栈帧

每次函数调用都会创建一个新的栈帧，包含以下内容：

- 返回地址：函数执行完毕后返回的位置。
- 参数：传递给函数的参数。
- 局部变量：函数内部定义的变量。

对于最简单的函数

```C
int main() {
    int a = 10;
    return 0;
}
```

对应的汇编代码如下

```
.text:00000001400017D0 ; int __cdecl main(int argc, const char **argv, const char **envp)
.text:00000001400017D0                 public main
.text:00000001400017D0 main            proc near               ; CODE XREF: __tmainCRTStartup+2EB↑p
.text:00000001400017D0                                         ; DATA XREF: .pdata:000000014000709C↓o
.text:00000001400017D0
.text:00000001400017D0 var_4           = dword ptr -4
.text:00000001400017D0
.text:00000001400017D0                 push    rbp
.text:00000001400017D1                 mov     rbp, rsp
.text:00000001400017D4                 sub     rsp, 30h
.text:00000001400017D8                 call    __main
.text:00000001400017DD                 mov     [rbp+var_4], 0Ah
.text:00000001400017E4                 mov     eax, 0
.text:00000001400017E9                 add     rsp, 30h
.text:00000001400017ED                 pop     rbp
.text:00000001400017EE                 retn
.text:00000001400017EE main            endp
```

栈帧变化如下:

开始前

```
高地址
      |
0x2000│  返回地址   <-- rsp
      ↓
低地址
```

`push rbp` 后

```
高地址
      |
0x2000│  返回地址
0x1FF8│  old rbp    <-- rsp
      ↓
低地址
```

`mov rbp, rsp` 后

```
高地址
      |
0x2000│  返回地址
0x1FF8│  old rbp    <-- rsp/rbp
      ↓
低地址
```

`sub rsp, 30h` 后

```
高地址
      |
0x2000│  返回地址
0x1FF8│  old rbp    <-- rbp
0x1FD8│  局部变量   <-- rsp
      ↓
低地址
```

`mov [rbp+var_4], 0Ah` 后

```
高地址
      |
0x2000│  返回地址
0x1FF8│  old rbp    <-- rbp
0x1FF4│  a = 10     <-- rbp+var_4
0x1FD8│  局部变量   <-- rsp
      ↓
低地址
```

`add rsp, 30h` 后

```
高地址
      |
0x2000│  返回地址
0x1FF8│  old rbp    <-- rbp/rsp
0x1FF4│  a = 10
0x1FD8│  局部变量
      ↓
低地址
```

`pop rbp` 后，`rbp` 跳转到 `old rbp` 的位置

```
高地址
      |
0x2000│  返回地址   <-- rsp
      ↓
低地址
```

`retn` 后，返回地址写入 `rip`

```
高地址
      |
0x2008|  父函数..   <-- rsp
0x2000│  返回地址
      ↓
低地址
```
