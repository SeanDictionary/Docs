# TypeScript 面经

## 1. TypeScript与JavaScript的区别是什么

TypeScript是JavaScript的超集，它扩展了JavaScript，主要区别包括：

- 类型系统：TypeScript引入了静态类型系统，允许开发者在编译时检查类型错误，而JavaScript是动态类型语言，在运行时才会发现类型错误。
- 编译过程：TypeScript需要编译成JavaScript才能在浏览器或Node.js环境中运行，而JavaScript可以直接运行。
- 语法扩展：TypeScript引入了许多新的语法特性，如接口、枚举、泛型等，这些特性在JavaScript中是不存在的。
- 开发工具支持：TypeScript提供了更好的开发工具支持，如智能提示、代码重构和错误检查等，而JavaScript的开发工具支持相对较弱。

## 2. TypeScript中的基本类型有哪些

TypeScript中的基本类型包括：

- `number`：表示数字类型，可以是整数或浮点数。
- `string`：表示字符串类型，可以使用单引号、双引号或反引号来定义字符串。
- `boolean`：表示布尔类型，只有两个值：`true` 和 `false`。
- `null`：表示空值，只有一个值：`null`。
- `undefined`：表示未定义的值，只有一个值：`undefined`。
- `void`：表示没有任何类型，通常用于函数没有返回值的情况。
- `never`：表示永远不会发生的值，通常用于函数抛出异常或进入死循环的情况。
- `any`：表示任意类型，可以赋值为任何类型的值，编译时不会进行类型检查。

对象类型包括：

- `object`：表示非原始类型的对象。
- `Array`：表示数组类型，可以使用泛型来指定数组元素的类型。
- `Tuple`：表示元组类型，可以包含不同类型的元素。
- `Enum`：表示枚举类型，可以定义一组命名的常数。
- `Map`：表示映射类型，可以将一个类型的属性映射到另一个类型。
- `Set`：表示集合类型，可以存储一组唯一的值。
- `Function`：表示函数类型，可以指定函数的参数类型和返回类型。
- `Class`：表示类类型，可以定义类的属性和方法。
- `Interface`：表示接口类型，可以定义对象的结构和行为。

## 3. 什么是类型断言？如何使用？

类型断言是一种告诉编译器某个值的类型的方式，通常用于当你知道一个值的类型，但编译器无法推断出来时。

类型断言有两种语法：

1. 尖括号语法：`<类型>值`
2. `as`语法：`值 as 类型`

## 4. 什么是泛型？为什么要使用泛型？

泛型是一种在定义函数、接口或类时使用的类型参数，可以在使用时指定具体的类型。泛型允许我们编写可重用的代码，同时保持类型安全。

使用泛型的好处包括：

- **提高代码的可重用性**：泛型允许我们编写适用于多种类型的函数、接口或类，而不需要为每种类型编写重复的代码。
- **保持类型安全**：使用泛型可以确保在编译时检查类型错误，

例如，当我们定义一个函数来处理数组时，可以使用泛型来指定数组元素的类型：

```typescript
function identity<T>(arg: T): T {
    return arg;
}
```

在这个例子中，`T` 是一个类型参数，可以在调用函数时指定具体的类型：

```typescript
let output = identity<string>("Hello, TypeScript!");
```

在这个例子中，我们将 `T` 指定为 `string`，因此函数 `identity` 将返回一个字符串类型的值。使用泛型可以使代码更加灵活和可重用，同时保持类型安全。

## 5. 装饰器是什么？如何使用？

装饰器是一种特殊的声明，可以附加到类、方法、属性或参数上，用于修改它们的行为。装饰器是在定义时被调用的函数，可以用来添加元数据、修改类或方法的行为等。

根据装饰器的应用对象不同，装饰器可以分为以下几种类型：

- **类装饰器**：应用于类的声明，可以用来修改类的构造函数或添加静态属性。

```typescript
function ClassDecorator(constructor: Function) {
}
```

- **方法装饰器**：应用于类的方法，可以用来修改方法的行为或添加元数据。

```typescript
function MethodDecorator(target: Object, propertyKey: string, descriptor: PropertyDescriptor) {
}
```

- **属性装饰器**：应用于类的属性，可以用来修改属性的行为或添加元数据。

```typescript
function PropertyDecorator(target: Object, propertyKey: string) {
}
```

- **参数装饰器**：应用于方法的参数，可以用来修改参数的行为或添加元数据。

```typescript
function ParameterDecorator(target: Object, propertyKey: string, parameterIndex: number) {
}
```

## 6. TypeScript中如何实现接口继承？

TypeScript中，接口通常用于定义对象的结构和行为，可以通过关键字 `extends` 来实现接口继承，从而扩展接口的功能。

一般常见接口如下：

```typescript
interface Person {
    name: string;
    age: number;
}
```

接口也可以用来描述函数类型：

```typescript
interface SearchFunc {
    (source: string, subString: string): boolean;
}
```

## 7. 如何在TypeScript中处理异步操作？

在TypeScript中处理异步操作，可以使用以下几种方式：

- **回调函数**：传统的处理异步操作的方式，通过将一个函数作为参数传递给另一个函数，在异步操作完成后调用该函数。但是此类方式需要所有的同步操作全部完成后才能执行回调函数，容易导致回调地狱。

```typescript
function fetchData(callback: (data: string) => void) {
    setTimeout(() => {
        callback("Data fetched");
    }, 1000);
}
```

- **Promise**：Promise 是一种更现代的处理异步操作的方式，它代表一个可能还未完成的操作，并允许我们在操作完成后执行相应的回调函数。

```typescript
function fetchData(): Promise<string> {
    return new Promise((resolve, reject) => {
        resolve("Data fetched");
    });
}
```

- **async/await**：async/await 是基于 Promise 的语法糖，可以让异步代码看起来更像同步代码，使用 `async` 关键字定义一个异步函数，使用 `await` 关键字等待一个 Promise 的结果。

```typescript
async function fetchData() {
    const response = await fetch("api/data");
    const data = await response.json();
    return data;
}
```

对于多个异步操作，可以使用 `Promise.all` 来同时等待多个 Promise 的完成，来实现并行处理，如果单纯使用 `await` 来等待多个异步操作，则会导致串行处理，效率较低。

## 8. 什么是条件类型？如何使用？

条件类型是一种根据类型关系进行选择的类型，可以根据条件表达式的结果来决定使用哪个类型。条件类型的语法如下：

```typescript
type Func<T> = T extends U ? X : Y;
```

在这个语法中，`T` 是要检查的类型，`U` 是要比较的类型，`X` 是当条件为真时使用的类型，`Y` 是当条件为假时使用的类型。

## 9. 简单介绍一下事件循环 (Event Loop) 机制

事件循环是 JavaScript 中处理异步操作的一种机制，它允许 JavaScript 在执行同步代码的同时处理异步事件。事件循环的核心概念包括：

- **调用栈 (Call Stack)**：用于存储正在执行的函数，当一个函数被调用时，它会被添加到调用栈的顶部，当函数执行完成后，它会从调用栈中移除。
- **消息队列 (Message Queue)**：用于存储待处理的异步事件，当一个异步事件完成后，它会被添加到消息队列中，等待调用栈空闲时被处理。
- **事件循环 (Event Loop)**：不断检查调用栈和消息队列的状态，如果调用栈为空，事件循环会从消息队列中取出一个事件并将其添加到调用栈中执行。

事件循环的流程如下：

1. 执行同步代码，直到调用栈为空。
2. 事件循环检查消息队列，如果有待处理的事件，则将其添加到调用栈中执行。
3. 重复步骤 1 和 2，直到所有事件都被处理完。

事件循环机制使得 JavaScript 能够处理异步操作，如网络请求、定时器等，同时保持单线程的执行模型。

任务队列里的任务其实还分为两种，**宏任务 (Macro Task)** 和 **微任务 (Micro Task)**，它们的执行顺序是：先执行所有的微任务，再执行一个宏任务。常见的宏任务包括 `setTimeout`、`setInterval`、`setImmediate` 等，而常见的微任务包括 `Promise.then`、`process.nextTick` 等。
