# 计算机八股

## 1. 网络模型

OSI七层模型：

1. **物理层**：负责传输原始比特流，定义了电气、机械、光学等方面的规范。
2. **数据链路层**：负责在物理层上建立、维护和释放数据链路，提供错误检测和纠正功能。
3. **网络层**：负责数据包的路由和转发，提供逻辑地址（如IP地址）和路径选择功能。
4. **传输层**：负责端到端的数据传输，提供可靠的连接和流量控制功能。
5. **会话层**：负责建立、管理和终止会话，提供同步和恢复功能。
6. **表示层**：负责数据的格式化、加密和解密，提供数据的语法和语义转换功能。
7. **应用层**：负责为用户提供各种网络服务，如HTTP、FTP、SMTP等。

TCP/IP四层模型：

1. **网络接口层**：对应OSI模型的物理层和数据链路层，负责在物理介质上传输数据。
2. **网络层**：对应OSI模型的网络层，负责数据包的路由和转发，提供IP地址和路径选择功能。
3. **传输层**：对应OSI模型的传输层，负责端到端的数据传输，提供可靠的连接和流量控制功能。
4. **应用层**：对应OSI模型的会话层、表示层和应用层，负责为用户提供各种网络服务，如HTTP、FTP、SMTP等。

**问**：为什么网络通信要分层？

**答**：网络通信分层的主要原因是为了简化设计和实现，促进模块化和标准化。每一层都有特定的功能和接口，使得不同层之间可以独立开发和维护，同时也方便了协议的设计和实现。此外，分层还可以提高系统的可扩展性和灵活性，使得不同的技术和协议可以在不同层次上进行替换和升级，而不影响其他层次的功能。

## 2. TCP和UDP

TCP（Transmission Control Protocol）是一种面向连接的传输层协议，它提供了可靠的数据传输服务。TCP通过建立连接、数据传输和连接终止三个阶段来确保数据的可靠性和顺序性。TCP适用于那些对数据完整性和可靠性要求较高的应用，如文件传输、电子邮件等。

UDP（User Datagram Protocol）是一种无连接的传输层协议，它提供了简单的消息传递服务。UDP不保证数据的可靠性、顺序和完整性，因此适用于那些对速度要求较高且可以容忍数据丢失的应用，如视频流、在线游戏等。

**问**：TCP和UDP是什么，有什么区别？

**答**：TCP和UDP都是传输层协议，但它们有以下区别：

- **TCP**是面向连接的，提供可靠的、有序的数据传输服务，适用于对数据完整性要求较高的应用。
- **UDP**是无连接的，提供简单的、不可靠的数据传输服务，适用于对速度要求较高且可以容忍数据丢失的应用。

**问**：TCP的握手和挥手过程是什么？为什么是三次握手和四次挥手？
**答**：TCP的握手过程是三次握手，挥手过程是四次挥手。

- 三次握手的过程如下：
    1. 客户端发送一个SYN（同步）包，表示请求建立连接。
    2. 服务器收到SYN包后，回复一个SYN-ACK（同步-确认）包，表示同意建立连接。
    3. 客户端收到SYN-ACK包后，回复一个ACK（确认）包，表示连接建立成功。

- 四次挥手的过程如下：
    1. 客户端发送一个FIN（结束）包，表示请求关闭连接。
    2. 服务器收到FIN包后，回复一个ACK包，表示确认关闭连接。
    3. 服务器发送一个FIN包，表示请求关闭连接。
    4. 客户端收到FIN包后，回复一个ACK包，表示确认关闭连接。

- 三次握手是为了确保双方都准备好建立连接，并且能够正确地发送和接收数据。四次挥手是为了确保双方都能够正确地关闭连接，并且不会丢失任何数据。

**问**：UDP有什么优缺点？如何保证UDP的可靠性？有哪些可靠UDP实现方法？
**答**：UDP的优点是简单、快速、开销小，适用于对速度要求较高且可以容忍数据丢失的应用。UDP的缺点是没有可靠性保证，数据可能会丢失、重复或乱序。

- 为了保证UDP的可靠性，可以在应用层实现一些机制，如：
    - **重传机制**：如果发送的数据没有收到确认，可以重传数据。
    - **序列号**：为每个数据包分配一个序列号，以便接收方检测丢失、重复或乱序的数据包。
    - **校验和**：为数据包计算校验和，以检测数据在传输过程中是否发生了错误。
    - **超时机制**：如果在一定时间内没有收到确认，可以认为数据包丢失，并进行相应的处理。

- 可靠UDP实现方法有：
    - **RUDP**：在UDP基础上添加可靠性机制，如重传、序列号和确认等。
    - **QUIC**：由Google开发的一种基于UDP的传输协议，提供了可靠性、低延迟和安全性等特性。
    - **KCP**：一种基于UDP的可靠传输协议，提供了高性能和低延迟的传输服务。
