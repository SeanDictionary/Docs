# Python面经

## 1. 深拷贝和浅拷贝

Python 中的深拷贝和浅拷贝是指在复制对象时，是否复制对象内部的子对象。

- 浅拷贝 `copy.copy()`：创建一个新的对象，但不复制对象内部的子对象。新对象中的子对象仍然引用原始对象中的子对象。
- 深拷贝 `copy.deepcopy()`：创建一个新的对象，并且递归地复制对象内部的子对象。新对象中的子对象与原始对象中的子对象完全独立。

## 2. 垃圾回收机制

垃圾回收机制（简称GC）是Python解释器自带一种机制，专门用来回收 不可用的变量值所占用的内存空间 。

Python 使用引用计数和垃圾回收机制来管理内存。当一个对象被创建时，Python 会为它分配内存，并且维护一个引用计数器来跟踪有多少个引用指向这个对象。当一个对象的引用计数器变为零时，Python 会自动回收这个对象占用的内存。

## 3. 可变/不可变数据类型

在Python中，数据类型可以分为可变类型和不可变类型。

- 可变类型：指的是对象的值可以被修改的类型，例如列表（list）、字典（dict）和集合（set）。
- 不可变类型：指的是对象的值不能被修改的类型，例如整数（int）、浮点数（float）、字符串（str）和元组（tuple）。

当你对一个可变对象进行修改时，实际上是在修改原始对象的内容，而不是创建一个新的对象。而对于不可变对象，每次修改都会创建一个新的对象。

## 4. 迭代器和生成器

迭代器（iterator）是一个对象，它实现了迭代协议，即包含 `__iter__()` 和 `__next__()` 方法。迭代器可以用于遍历容器类型的数据结构，例如列表、元组和字典。

生成器（generator）是一种特殊的迭代器，它使用 `yield` 关键字来生成值。生成器可以在需要时动态地生成值，而不是一次性创建一个完整的列表或其他数据结构。这使得生成器非常适合处理大量数据或无限序列。

生成器的优点包括：

- **内存效率高**：生成器可以按需生成值，而不是一次性创建所有值，从而节省内存。
- **代码简洁**：生成器可以使用简单的 `yield` 语句来实现复杂的迭代逻辑，使代码更加简洁。
- **延迟计算**：生成器在需要时才计算下一个值，这可以提高程序的性能。

## 5. 全局解释器锁 GIL

全局解释器锁（Global Interpreter Lock，简称GIL）是Python解释器中的一个机制，用于保护访问Python对象的线程安全。GIL确保**同一时刻只有一个线程可以执行Python字节码**，这意味着即使在多线程环境中，Python程序也无法充分利用多核CPU的性能。

所以，多线程在python中的具体效果最终都是伪并行，主要适用于I/O密集型任务，而对于CPU密集型任务，通常建议使用多进程（multiprocessing）来实现并行计算，以充分利用多核CPU的性能。

## 6. 装饰器

装饰器（decorator）是Python中的一种设计模式，它允许在不修改函数代码的情况下，动态地为函数添加功能。装饰器本质上是一个函数，它接受一个函数作为参数，并返回一个新的函数。

例如，我们可以创建一个简单的装饰器来打印函数的调用信息：

```python
def print_call_info(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

## 7. with as 语法

`with as` 语法是Python中的上下文管理器（context manager）的一种用法，它用于简化资源管理，例如文件操作、网络连接等。使用 `with as` 语法可以确保在代码块执行完毕后，自动释放资源，无论代码块是否正常执行完毕。

构造类时可以通过实现 `__enter__()` 和 `__exit__()` 方法来处理 `with as` 语法的进入退出操作，自动管理资源的分配和释放。例如：

```python
class MyContextManager:
    def __enter__(self):
        print("Entering the context")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting the context")
```

## 8. *args和**kwargs

`*args` 和 `**kwargs` 是Python中用于函数定义的特殊语法，用于处理可变数量的参数。
- `*args` 用于传递任意数量的位置参数，这些参数会被收集到一个元组中。
- `**kwargs` 用于传递任意数量的关键字参数，这些参数会被收集到一个字典中。

## 9. 惰性求值

惰性求值（Lazy Evaluation）是一种编程技术，它延迟计算表达式的值，直到真正需要它的时候才进行计算。这种技术可以提高程序的性能和效率，尤其是在处理大量数据或复杂计算时。

## 10. 实例方法、类方法和静态方法

- 实例方法：需要实例化对象才能调用，默认第一个参数是 `self`，表示实例对象。
- 类方法：使用 `@classmethod` 装饰器定义，第一个参数是 `cls`，表示类对象，可以通过类名或实例对象调用。
- 静态方法：使用 `@staticmethod` 装饰器定义，不需要默认参数，可以通过类名或实例对象调用，通常用于工具函数。

## 11. `__slots__`

`__slots__` 是Python类中的一个特殊属性，用于限制类实例可以动态添加的属性。通过定义 `__slots__`，可以显著减少内存占用，因为它避免了为每个实例创建一个 `__dict__` 来存储属性。

```python
class MyClass:
    __slots__ = ['name', 'age']

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

## 12. CPython和PyPy

CPython是Python的官方实现，使用C语言编写，是目前最广泛使用的Python解释器。PyPy是另一个Python解释器，使用Python语言编写，具有更好的性能和内存管理能力。

CPython 将 Python 编译为中间字节码然后由虚拟机解释，而 PyPy 使用实时（JIT）编译将 Python 代码转换为本地机器的汇编语言 。

## 13. `.py` 文件和`.pyc`文件

`.py` 文件是Python源代码文件，包含了Python程序的文本代码。而 `.pyc` 文件是Python编译后的字节码文件，是由Python解释器将 `.py` 文件编译生成的。`.pyc` 文件可以提高程序的加载速度，因为它们已经被编译为字节码，可以直接被Python虚拟机执行，而不需要再次解析源代码。

当 Python 解释器第一次运行一个 `.py` 文件时，它会将源代码编译成字节码，并将字节码保存在 `.pyc` 文件中。
