# TypeScript

TypeScript 是 JavaScript 的一个超集，添加了类型注解和基于类的面向对象编程。

运行时 TypeScript 代码需要被编译成 JavaScript 才能在浏览器或 Node.js 中运行。编译器会检查类型错误，并将 TypeScript 代码转换为兼容的 JavaScript 代码。

```bash
tsc a.ts --outDir output
```

## tsconfig.json

tsconfig.json 是 TypeScript 项目的配置文件，指定了编译器选项、包含和排除的文件等，常见的配置选项包括：

```json
{
    "compilerOptions": {
        "target": "ES2020", // 编译后的 JavaScript 版本, ES5, ES6/ES2015, ES2020...
        "lib": ["ES2020", "DOM"], // 编译时包含的库文件, ES5, ES6/ES2015, ES2020, DOM...
        "module": "commonjs", // 模块系统, 控制编译后的模块格式, commonjs, NodeNext, es6, esnext...
        "strict": true, // 启用所有严格类型检查选项
        "outDir": "./dist" // 输出目录
    },
    "baseUrl": ".", // 基础路径
    "paths": {
        "@/*": ["src/*"], // 模块路径别名
        "@components/*": ["src/components/*"] // 模块路径别名
    },
    "include": ["src/**/*"], // 指定需要编译的文件，包含 src 目录下的所有文件
    "exclude": ["node_modules", "dist"] // 指定不需要编译的文件或目录
}
```

## 变量声明

两种定义变量的关键词，`let` 和 `var`，现在常用 `let` 来声明变量

1. `let` 是块级作用域，而 `var` 是函数级作用域
2. `var` 允许变量被重新声明，而 `let` 不允许
3. `var` 变量会被提升到函数顶部，而 `let` 不会
4. `var` 变量会被绑定到全局对象（在浏览器中是 `window`），而 `let` 变量不会
5. `var` 变量在循环中会有意外行为，而 `let` 变量在循环中会正确地捕获每次迭代的值

```typescript
for (var i = 0; i < 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 0);
}
/* 
3
3
3
*/
```

```typescript
for (let i = 0; i < 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 0);
}
/* 
1
2
3
*/
```

常量用 `const` 声明，声明后不能被重新赋值，注意这里的赋值不是指对象不可变，而是指变量的引用不可变。

```typescript
const a = 1;
const map = new Map();
map.set("key", "value");
```

### 特殊变量类型

`null` 和 `undefined` 是 JavaScript 中的两种特殊值，分别表示“无值”和“未定义”。在 TypeScript 中，默认情况下，`null` 和 `undefined` 是所有类型的子类型，这意味着你可以将 `null` 和 `undefined` 赋值给任何类型的变量。

- `null` 通常是指向的一个空对象，用 typeof 检测 `null` 返回是 object。
- `undefined` 则表示一个变量已经声明但尚未赋值，或者一个函数没有返回值时默认返回 `undefined`。

`never` 是 TypeScript 中的一个特殊类型，表示永远不会发生的值。它通常用于函数的返回类型，表示该函数永远不会返回任何值，例如抛出异常或进入死循环。

`any` 是 TypeScript 中的一个特殊类型，表示任意类型。使用 `any` 类型的变量可以赋值为任何类型的值，并且在编译时不会进行类型检查。过度使用 `any` 可能会导致代码变得不安全和难以维护

`unknown` 是 TypeScript 中的一个特殊类型，表示未知类型。与 `any` 不同，`unknown` 类型的变量在编译时需要进行类型检查，必须进行类型断言或类型缩小才能使用。这使得 `unknown` 类型比 `any` 更安全，因为它强制开发者在使用之前明确地处理未知类型的值。

## 接口和继承

接口（Interface）是 TypeScript 中的一种结构化类型，用于定义对象的形状和行为。接口可以包含属性、方法和索引签名等成员。接口还支持继承，可以通过 `extends` 关键字来实现接口之间的继承关系。

```typescript
interface Person {
    name: string;
    age: number;
    greet(): void;
}
interface Employee extends Person {
    employeeId: number;
    work(): void;
}
```

接口也可以重复声明，TypeScript 会将它们合并成一个接口：

```typescript
interface Person {
    name: string;
}
interface Person {
    age: number;
}
```

在这个例子中，`Person` 接口被声明了两次，TypeScript 会将它们合并成一个接口，包含 `name` 和 `age` 两个属性。

接口还可以定义函数类型：

```typescript
interface Add {
    (a: number, b: number): number;
}
```

接口还可以定义索引签名：

```typescript
interface StringArray {
    [index: number]: string;
}
```

关于继承，接口可以通过 `extends` 关键字来继承另一个接口的成员：

```typescript
interface Shape {
    color: string;
}
interface Circle extends Shape {
    radius: number;
}
```

## 异步函数

### 回调函数（早期异步实现）

TypeScript 支持异步函数（async functions），它们是基于 Promise 的语法糖，可以让异步代码看起来更像同步代码。使用 `async` 关键字定义一个异步函数，使用 `await` 关键字等待一个 Promise 的结果。

早期的异步编程依赖于回调函数实现，例如

```typescript
function fetchData(callback: (data: string) => void) {
    setTimeout(() => {
        callback("Data fetched");
    }, 1000);
}
```

如果定时器设置为 0 毫秒，也不代表回调函数会立即执行，而是会被放入事件队列中，等待当前执行栈清空后才会执行。这是 JavaScript 的事件循环机制决定的。

此类早期通过回调函数实现的异步编程方式，容易导致回调地狱（callback hell），使代码难以阅读和维护。为了解决这个问题，现代 JS/TS 先后引入了 Promise 和 async/await 语法，使得异步代码更清晰和易于管理。

```typescript
async function fetchData() {
    const response = await fetch("api/data");
    const data = await response.json();
    console.log(data);
}
```

### Promise 对象

Promise 是一个对象，用来表示一个异步操作。

Promise 有三种状态：

1. **进行中（Pending）**：初始状态，既不是成功也不是失败。
2. **成功（Fulfilled）**：操作成功完成，Promise 的值为操作结果。
3. **失败（Rejected）**：操作失败，Promise 的值为拒绝原因。

Promise 基本结构通常如下：

```typescript
const promise = new Promise((resolve, reject) => {
    // 异步操作
    if (/* 操作成功 */) {
        resolve(result); // 传递结果
    } else {
        reject(error); // 传递错误
    }
});
```

对于 Promise 对象，可以使用 `then` 方法来处理成功的结果，使用 `catch` 方法来处理失败的结果：

```typescript
promise
    .then((result) => {
        console.log("操作成功，结果:", result);
    })
    .catch((error) => {
        console.error("操作失败，错误:", error);
    });
```

于是通过对 Promise 链式调用，可以写成如下

```typescript
promise
    .then((result) => {
        console.log("操作成功，结果:", result);
        return anotherAsyncOperation(result); // 返回另一个 Promise
    })
    .then((anotherResult) => {
        console.log("另一个操作成功，结果:", anotherResult);
    })
    .catch((error) => {
        console.error("操作失败，错误:", error);
    });
```

对于同时执行多个 Promise，可以使用 `Promise.all` 方法来等待所有 Promise 都完成：

```typescript
Promise.all([promise1, promise2, promise3])
    .then(([result1, result2, result3]) => {
        console.log("所有操作成功，结果:", result1, result2, result3);
    })
    .catch((error) => {
        console.error("至少一个操作失败，错误:", error);
    });
```

另外还有 `Promise.race`、`Promise.allSettled` 等方法，分别用于等待第一个完成的 Promise 和等待所有 Promise 都完成（无论成功还是失败）。

### async/await

async/await 是 ES2017 引入的基于 Promise 异步编程语法糖，让异步代码看起来像同步代码。。使用 `async` 关键字定义一个异步函数，使用 `await` 关键字等待一个 Promise 的结果。

```typescript
async function fetchData() {
    const response = await fetch("api/data");
    const data = await response.json();
    console.log(data);
}
```

对于 Promise 对象的错误处理，可以使用 `try/catch` 块来捕获异常。
