# Node.js

Node.js 提供了脱离浏览器的 JavaScript 运行环境，允许开发者使用 JavaScript 来编写服务器端的代码。它基于 Chrome V8 引擎，具有高性能和事件驱动的特点，使得它非常适合构建高并发的网络应用程序。

## 一些命令行工具

- `node`：Node.js 的核心模块，提供了许多内置的功能，如文件系统、网络通信等。
- `npm`：Node.js 的包管理器，允许开发者安装和管理第三方库和工具。
- `pnpm`：一个更快、更高效的包管理器，提供了更好的性能和依赖管理。
- `npx`：一个随 npm 一起安装的工具，允许开发者直接运行安装在 node_modules 中的包，而无需全局安装。
- `tsc`：TypeScript 的编译器，用于将 TypeScript 代码编译成 JavaScript 代码。
- `tsx`：一个现代的 TypeScript 执行器，支持最新的 TypeScript 特性，并提供更快的执行速度。


## 主要特点

1. **事件驱动**：Node.js 使用事件驱动的架构，能够处理大量的并发连接，而不会阻塞线程。这使得它非常适合构建实时应用程序，如聊天应用和在线游戏。
2. **非阻塞 I/O**：Node.js 的 I/O 操作是非阻塞的，这意味着它可以同时处理多个请求，而不会等待某个操作完成。这提高了应用程序的性能和响应速度。
3. **单线程**：虽然 Node.js 是单线程的，但它通过事件循环和异步编程模型来处理并发请求。这使得它能够高效地利用系统资源。
4. **丰富的模块生态系统**：Node.js 拥有一个庞大的模块生态系统，开发者可以通过 npm（Node Package Manager）轻松地安装和管理第三方库和工具。

## 常用模块

- `http`：用于创建 HTTP 服务器和客户端。
- `fs`：用于文件系统操作，如读取和写入文件。
- `path`：用于处理文件和目录路径。
- `express`：一个流行的 web 框架，简化了服务器端开发。
- `socket.io`：用于实现实时通信的库，常用于聊天应用和在线游戏。

## 包管理器

Node.js 使用 npm 作为其包管理器，允许开发者轻松地安装、更新和管理项目依赖。通过 npm，开发者可以访问数百万个开源包，极大地扩展了 Node.js 的功能。

pnpm 是另一个包管理器，提供了更快的安装速度和更高效的依赖管理。它通过使用虚拟文件系统来避免重复安装相同的依赖，从而节省磁盘空间和提高性能。

package.json 是 Node.js 项目的配置文件，包含了项目的元数据、依赖项和脚本等信息。它是 npm 和 pnpm 管理项目依赖的核心文件。

在项目开发时，通过 `npm install <package-name>` 或 `npm install -D <package-name>` 可以安装生产依赖或开发依赖。安装完成后，相关的包信息会被记录在 package.json 文件中，方便后续的维护和更新。

在 clone 项目后，开发者可以通过 `npm install` 命令来根据 package.json 文件安装项目所需的所有依赖，确保项目能够正常运行。
